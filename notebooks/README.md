# Notebooks

This folder contains the Jupyter notebooks for the India School Education Equity & Infrastructure Analytics project.

- 01_data_inspection.ipynb — Inspect the UDISE+ datasets
- 02_data_cleaning.ipynb — Clean and validate the data
- 03_data_merging.ipynb — Merge school-level datasets
- 04_eda_and_statistics.ipynb — Exploratory and statistical analysis
- 05_clustering.ipynb — Cluster schools by education indicators
